# Dynamics core: Python bindings

Python bindings for [dynamics-core](https://github.com/chethandvg/dynamics-core), built from the Rust core with PyO3 and maturin. Function names and results are identical to the Rust crate; the shared golden vectors check it in CI.

```bash
pip install "git+https://github.com/chethandvg/dynamics-core@v0.1.0#subdirectory=bindings/python"
```
