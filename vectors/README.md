# Golden vectors

Each `*.json` file here is a list of input/output cases that the Rust crate, the Python bindings and the WebAssembly bindings must all reproduce. The format is `golden-vectors@1` from [evidence-kernel](https://github.com/chethandvg/evidence-kernel).

The vectors are generated by [`generate.py`](generate.py), the reference (oracle) implementation. Almost every result here is irrational, so the oracle works in Python's `decimal` module at 400 significant digits, starting from the exact values of the input doubles, and rounds each result once. It shares no code with the Rust crate: peaks come from iterating the recurrence, and pulse counts are checked against their definition. Regenerate with:

```bash
python vectors/generate.py
```
